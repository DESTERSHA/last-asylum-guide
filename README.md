# Last Asylum: Plague — гайд альянса (на русском)

Статический сайт для GitHub Pages: прокачка героев, отряды, снаряжение, Дуэль альянсов, правила сервера, КвК, термины, фишки.

## Как править

1. Текст страниц лежит в `src/*.html` (только содержимое страницы; первая строка — JSON с заголовком и описанием).
2. Общая шапка, меню и подвал — в `tools/build.py`. Стили — `assets/style.css`, скрипт — `assets/app.js`.
3. Собрать страницы: `python tools/build.py`
4. Проверить ссылки и картинки: `python tools/check_links.py`
5. Закоммитить и запушить — GitHub Pages обновится сам через 1–2 минуты.

Скриншоты не хранятся в репозитории: они подгружаются с сайтов-источников, у каждого подписан источник.
Фанатский проект, к разработчикам игры отношения не имеет.
